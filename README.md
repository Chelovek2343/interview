# Сервис заявок на автоматизацию

Тестовое задание по ТЗ. Фронт: HTML + CSS + Vanilla JS. Бэкенд: Node.js + Express.

## Запуск
    npm install
    npm start
Открыть http://localhost:3000

## Роли
Переключатель в шапке: «Сотрудник» (создаёт и правит свои заявки) и «Аналитик»
(видит все, меняет статус и комментарий, скачивает Markdown для БТ).
Пользователь задаётся вручную (латиницей). Настоящей авторизации нет (ТЗ, п. 10).

## API
- GET    /api/requests          список (сотрудник: свои, аналитик: все)
- GET    /api/requests/:id      одна заявка
- POST   /api/requests          создать (сотрудник)
- PUT    /api/requests/:id      изменить свою заявку в статусах «Новая» и «На уточнении»
- PATCH  /api/requests/:id      статус и комментарий (аналитик)
Роль и пользователь передаются заголовками X-Role и X-User.

## Упрощения
- Хранение в файле data.json (вместо БД).
- Роли по заголовкам вместо SSO.
- Черновик в localStorage.
- Не реализованы: п. 6.1 (время на единицу), вложения, уведомления.
